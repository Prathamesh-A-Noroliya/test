CHANGE 1 — FIX GLOBAL SCROLL BEHAVIOUR (HIGH PRIORITY)
Current Problem

Whenever the user scrolls to the bottom of one page (for example Dashboard) and then navigates to another section (Smart Irrigation, Scan, Analytics, History, AI Bhoomi, etc.), the next page opens at the exact previous scroll position.

This creates a poor user experience.

Example:

User scrolls to bottom of Dashboard

↓

Clicks Smart Irrigation

↓

Smart Irrigation opens at bottom

↓

User must manually scroll back up.

This should NEVER happen.

Required Behaviour

Whenever navigation happens between any routes/pages:

Dashboard
Crop Scan
Analytics
Smart Irrigation
Scan History
AI Bhoomi
Settings
Profile
Every future page

the page MUST automatically start from:

scrollY = 0

The transition should feel natural.

Implementation

Implement a global ScrollToTop component.

Whenever the pathname changes:

    top:0,
    left:0,
    behavior:"instant"
})

(or equivalent implementation depending on framework.)

Do NOT use smooth scrolling here.

The new page should instantly begin from the top.

The fix must work:

✓ Desktop

✓ Tablet

✓ Mobile

✓ Browser refresh

✓ Client-side routing

✓ Vercel deployment
